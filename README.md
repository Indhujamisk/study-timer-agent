# study-timer-agent
# 📚 Study Timer Agent (AI Agents Hackathon 2025)

A simple desktop-based study timer agent built in Python using `tkinter`. Inspired by the agent architecture used in frameworks like Azure AI Agents SDK and Semantic Kernel.

## 🎯 Features
- Start/Stop a 25-minute Pomodoro-style study timer
- Desktop app with clean UI
- Easily extendable with advanced AI agent frameworks in the future

## 🛠️ Technologies
- Python
- Tkinter for UI
- `time` and `threading` modules

## 🧠 Inspired By
- Azure AI Agents SDK
- Semantic Kernel
- Autogen
- Microsoft 365 Agents SDK

## 🚀 Getting Started
bash
python study_timer_ui.py
